## Where Does Liquidity Cluster? (Where Are the Crowd's Orders?)

You asked: "How do I know where the crowd is clustered?"

You don't need order flow data or institutional tools. Retail traders are PREDICTABLE because they all learn the same things from the same sources.

### Rule: If YOU Can See It on a Clean Chart, Everyone Can. And Their Orders Are There.

## The 7 Liquidity Magnets

### 1. Swing Highs and Swing Lows (The Biggest Pool)

```
    Every visible swing high has SELL STOPS above it:
    - Retail longs use the high as "resistance" → SL above
    - Short sellers enter breakouts above → BUY STOP orders above
    
            Sell stops clustered here
                    ↓↓↓↓↓
    ─────────── ═══════════ ────────────
                    /\
                   /  \
                  /    \
                 /      \
                /        \
               /          \
              /            \
    ─────────── ═══════════ ────────────
                    ↑↑↑↑↑
            Buy stops clustered here
    
    Every visible swing low has BUY STOPS below it:
    - Retail shorts use the low as "support" → SL below
    - Breakout traders have BUY STOP orders below for shorts
```

**Your action**: Mark the most obvious swing highs and swing lows on H4 and H1. These are WHERE the sweep will target. If price is moving toward a clean high/low = it's going to sweep it.

### 2. Equal Highs / Equal Lows (Double/Triple Tops and Bottoms)

```
    EQUAL HIGHS (Massive liquidity above):
    
    ─────────── ═══════════════════════ ─────────── 
                /\              /\
               /  \            /  \
              /    \          /    \
             /      \        /      \
            /        \      /        \
           /          \    /          \
          /            \  /            \
                        \/

    Two or more highs at nearly the same level = EXTREME liquidity above.
    Every textbook says "double top = resistance = sell"
    → Everyone places SELL orders at the level
    → Everyone places BUY STOPS just above
    → Smart money SWEEPS above the equal highs to fill
    → THEN the real move down begins
    
    EQUAL LOWS (Massive liquidity below):
    
          /            \  /            \
         /              \/              \
        /                                \
       /      \                /          \
              \              /
               \            /
                \          /
    ─────────── ═══════════════════════ ───────────
    
    Same logic inverted. Equal lows = extreme liquidity below.
```

**The counter-intuitive truth**: Double tops/bottoms are NOT reversal signals. They are TARGETS. Price will sweep beyond them before reversing. The reversal starts AFTER the sweep, not AT the equal level.

### 3. Round Numbers / Psychological Levels

```
    EURUSD examples:
    
    1.1000 ─── Major round number (huge liquidity)
    1.0950 ─── Minor round number
    1.0900 ─── Major round number
    1.0850 ─── Minor round number
    1.0800 ─── Major round number
    
    Every 100-pip round number has:
    - Pending orders from retail ("I'll buy if it hits 1.0800")
    - Stop losses from positions ("My SL is at 1.0800")
    - Institutional orders (banks execute client orders at round numbers)
    
    Every 50-pip level has moderate clustering.
    Every 00-pip level has massive clustering.
```

**Your action**: Always note which round numbers are near your setup. If your entry zone is near 1.0800, expect volatile behavior around that level.

### 4. Previous Day High / Previous Day Low (PDH/PDL)

```
    Yesterday's candle on D1:
    
    PDH → ─────────── ═════════ ─── Orders above: breakout buys + SL of shorts
          |           |
          |  Yesterday|
          |  range    |
          |           |
    PDL → ─────────── ═════════ ─── Orders below: breakout sells + SL of longs
    
    Institutional algorithms specifically target PDH/PDL.
    During London Open, the first move is often a sweep of PDH or PDL.
```

**Your action**: Mark PDH and PDL every morning before trading. If the first move of the day takes out PDH or PDL, that's a sweep candidate — watch for reversal.

### 5. Session Highs / Session Lows (Asian Range)

```
    Asian session (00:00-07:00 GMT) creates a range:
    
    Asian High → ═══════════════ ─── London will sweep this
                 |              |
                 | Asian Range  |
                 |  (low volume |
                 |   tight box) |
    Asian Low →  ═══════════════ ─── Or London will sweep this
    
    London Open strategy:
    1. Mark the Asian range high and low
    2. Wait for London to sweep ONE side
    3. Enter in the opposite direction after the sweep
    
    This works because:
    - Asian session has low volume → tight range → orders cluster at edges
    - London brings HIGH volume → sweeps the stops at the edges
    - After the sweep, London establishes the daily direction
```

**This is one of the most consistent setups in forex.** Asian range sweep + H1 BoS + M15 confluence = high-probability entry.

### 6. Trendline Liquidity (Channel/Wedge Edges)

```
    ASCENDING CHANNEL:
    
    Breakout traders have buy stops above the channel:
                ↓↓↓↓↓
    ═══════════════════════════ ← Stops above upper edge
           /\         /\       /
          /  \       /  \     /
         /    \     /    \   /
        /      \   /      \ /
       /        \ /        / 
      /          /        / ← Trendline (everyone sees it)
     /          /        /
    ═══════════════════════════ ← Stops below lower edge
                ↑↑↑↑↑
    
    When price breaks ABOVE the upper channel edge:
    - Breakout traders buy (their entries = liquidity)
    - Stop-losses from channel shorts trigger (more liquidity)
    - Smart money uses this liquidity to SELL
    - Price comes back inside the channel = the "deviation"
    
    Your prompt calls this a "false breakout" or "deviation."
    It's the channel version of a liquidity sweep.
```

### 7. FVG (Fair Value Gap) as Liquidity

```
    Unfilled FVGs act as magnets:
    
    Price tends to RETURN to unfilled FVGs before continuing.
    Institutional algorithms specifically target these gaps.
    
              ____
             |    |  Candle 3
             |    |
             |____|
                     ← GAP (unfilled orders)
                ____
               |    |  Candle 2 (big move)
               |    |
               |    |
               |    |
               |____|
             ____
            |    |  Candle 1
            |    |
            |____|
    
    The GAP is where orders didn't get filled during the fast move.
    Price returns to "fill" these orders before continuing.
    When the FVG is at the same level as an OB = strongest entry.
```

## When Do Market Makers Enter? Reading the Footprint

You asked: "How do I know when market makers enter?"

You can't see their orders in real time. But you can see the EVIDENCE after they act. Here are the 5 footprints:

### Footprint 1: The Displacement Candle
```
    A displacement candle is abnormally large compared to recent candles.
    It shows that a large order was executed.
    
    Normal candles:        Displacement:
    ____                   ____
   |    |                 |    |
   |____|                 |    |
    ____                  |    |
   |    |                 |    |
   |____|                 |    |
    ____                  |    |
   |    |                 |    |  ← This candle is 3-4x larger
   |____|                 |    |     than recent candles.
    ____                  |    |     A large order was filled.
   |    |                 |    |
   |____|                 |____|
    ____                  
   |    |
   |____|
   
    If displacement appears AFTER a sweep = smart money entered.
    Direction of displacement = direction of the trade.
```

### Footprint 2: The Rejection Wick
```
    A long wick shows that a level was tested and REJECTED.
    Someone defended that level with size.
    
    Long upper wick (selling pressure):
    
         |  ← Sellers pushed price back down from here
         |
        _|_
       |   |  ← Body is small relative to wick
       |___|
    
    Long lower wick (buying pressure):
    
        ___
       |   |  ← Body is small relative to wick
       |___|
         |
         |  ← Buyers pushed price back up from here
    
    If the rejection happens at a liquidity level = smart money defended it.
```

### Footprint 3: Absorption (Volume Without Movement)
```
    Price barely moves despite high-volume candles:
    
    Normal:                 Absorption:
    
    High volume = big move  High volume = tiny move
    
        ____                   ____
       |    |                 |____|  ← Big volume
       |    |                  ____
       |    |                 |____|  ← Big volume
       |    |                  ____
       |____|                 |____|  ← Big volume
    
    Price isn't moving because a large player is ABSORBING
    all the orders at this level. They're accumulating a position.
    
    After absorption ends, price EXPLODES in the direction
    the absorber was positioning for.
```

### Footprint 4: Break of Structure with Momentum
```
    A clean BoS (one candle breaks through) = weak signal.
    A BoS with MOMENTUM (multiple fast candles) = strong signal.
    
    Weak BoS:               Strong BoS:
    
    Previous level ───────   Previous level ──────
              \                         \
               \                         \
                \                         \
                 \___                      \
                                            \
                                             \
                                              \  ← Multiple fast
                                               \    candles
                                                \    breaking through
                                                 \___
    
    Strong BoS = institutional momentum. Someone big is committed.
    Weak BoS = could be a fakeout. Wait for retest.
```

### Footprint 5: Time of Day
```
    Smart money operates during kill zones:
    
    07:00-07:30 GMT: London opening "sweep" → Asian range targeted
    07:30-10:00 GMT: London main move → institutional direction established
    12:00-12:30 GMT: NY opening → potential continuation or reversal of London
    12:30-15:00 GMT: NY main move → highest volume of the day
    
    If you see a sweep + displacement at 08:00 GMT = high probability (London is acting)
    If you see a sweep + displacement at 22:00 GMT = low probability (no institutional volume)
    
    Time validates the footprint.
```

## The "Crowd Detector" Cheat Sheet

| What You See on the Chart | Where the Crowd Is | What Will Happen |
|---|---|---|
| Obvious swing high on H1/H4 | Stops ABOVE it (shorts + longs' breakout entries) | Price will sweep above, then reverse down |
| Obvious swing low on H1/H4 | Stops BELOW it (longs + shorts' breakout entries) | Price will sweep below, then reverse up |
| Equal highs (double top) | MASSIVE stops above (everyone sees the "resistance") | Price sweeps above both, then drops hard |
| Equal lows (double bottom) | MASSIVE stops below (everyone sees the "support") | Price sweeps below both, then rallies hard |
| Round number (1.0800, 1.0900) | Limit orders + stops from all timeframe traders | Expect volatility near these levels |
| Asian session range | Stops above AND below the range edges | London sweeps one side, then moves opposite |
| Trendline (obvious on any TF) | Stops beyond the trendline | Price breaks through trendline (sweep), then reverses back inside |
| Unfilled FVG | Algorithms targeting the gap | Price returns to fill the gap, then continues original direction |
